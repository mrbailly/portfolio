# William Baiden · UX writing portfolio

A static, single-page UX writing portfolio with two case studies:

1. Welcome flow and incentive messaging (lifecycle emails and a welcome voucher)
2. A homepage built around one question (content hierarchy and stakeholder influence)

Files: `index.html` and `styles.css`. No build step and no external dependencies.

## Preview

Open `index.html` in a browser.

## Confidentiality rules for this repo

- The employer isn't named anywhere on the site. Keep it that way unless you have written permission.
- All visuals and example copy are original illustrations, labelled as such. Never add internal screenshots, PDFs, design files, logos, offer amounts or detailed terms.
- Performance figures stay at the level already published on the site (early, flow-level, not attributed to single copy changes).

## Publish with GitHub Pages (after review)

1. Check every claim on the page (see the verification list in the review notes).
2. Repository → Settings → Pages → Build and deployment → Source: "Deploy from a branch".
3. Branch: `main`, folder: `/ (root)`. Save.
4. Wait a minute, then open `https://mrbailly.github.io/portfolio/` on desktop and phone.
5. Paste that URL into the Booking.com application.
